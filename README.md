# Splunk Detection-as-Code

Splunk detections as YAML files, validated in CI and built into a deployable `savedsearches.conf`.

**Skills:** Splunk and SPL, MITRE ATT&CK, detection engineering, Python, YAML, GitHub Actions

**Value:** Every rule change is reviewed and traceable, false positives are documented, and detection coverage is visible at a glance.

Setup and rule format: [docs/SETUP.md](docs/SETUP.md)
